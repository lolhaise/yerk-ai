# Contributing

How to report a bug, ask a question or offer a change to Yerk AI. It is a personal tool with one maintainer, built in the open, so the rules are short:

- Issues are welcome: a bug, a question, a page of the docs that reads wrong. Say what you ran, on which commit, and what you saw.
- Pull requests are by invitation for now. Open an issue first; if a change is wanted, the maintainer says so there.
- A security problem goes through SECURITY.md, never an issue.

A change follows STYLE.md for every word a user sees, adds its block to CHANGELOG.md, and leaves `uv run pytest` green.
